# neondrop-assets

Обложки и превью магазина NEON DROP.

Хранятся отдельно от хостинга: карточки каталога ссылаются на файлы отсюда
по прямым ссылкам, поэтому переезд магазина на другой хостинг их не теряет.

Ссылка для колонки «Обложка» в таблице каталога:

```
https://raw.githubusercontent.com/ВЛАДЕЛЕЦ/neondrop-assets/main/covers/ИМЯ.png
```

Здесь только рекламные материалы. Файлы товаров — платные, лежат в приватном
репозитории магазина и выдаются приложением после покупки.
